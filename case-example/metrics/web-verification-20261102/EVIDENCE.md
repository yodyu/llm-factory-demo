# 证据脱敏说明

公开报告、日志和辅助脚本统一使用以下占位路径，复现时须替换为实际服务器配置：

| 占位路径 | 含义 |
| --- | --- |
| `/path/to/llm-factory` | 服务器项目根目录；回环挂载对应的路径统一为此形式 |
| `/path/to/private-config` | 仓库外的应用私有配置目录 |
| `/path/to/private-model` | 仓库外的已授权模型配置目录 |
| `/path/to/server-home` | 其他服务器用户目录 |
| `/path/to/local-home` | 本地用户目录 |

安装日志、错误栈和导出记录中的绝对路径已脱敏，因此公开文本不是服务器原始文件的逐字副本。模型输出、任务 ID、检测指标、算法源码和验证结论保持原记录；截图和交付 ZIP 保持原字节。服务器上的原始运行记录及私有配置不作修改。

各子目录及整个报告目录的 `manifest.sha256` 对当前公开附件重新计算；它们校验脱敏后的文件，而非未公开的原始日志。机器检查结果见[脱敏核验](redaction-checks.json)。
